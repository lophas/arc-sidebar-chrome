## Arc Side of the Chrome 4.2.2

*Spaces, tabs & a little harmony.*

- Keep current website exceptions when restoring an older backup containing an empty exception list.
- Preserve intentional empty lists in newly created backups, and continue restoring non-empty lists from older backups.
- Retain the backup’s automatic discard timeout and other settings while handling legacy exception lists safely.

If an older restore already cleared your list, choose **Restore default exceptions**, then **Save website exceptions** in Options once to bring the starting list back.

For an unpacked installation, download `arc-side-of-the-chrome-v4.2.2.zip`, replace the files in your existing folder and click **Reload** at `chrome://extensions`.
For a Chrome Web Store upload, use `arc-side-of-the-chrome-v4.2.2-webstore.zip`.
