## Arc Side of the Chrome 3.0.1

*Spaces, tabs & a little harmony.*

Arc Sidebar for Chrome is now **Arc Side of the Chrome**. The new name appears throughout the extension, its settings, search, webpage context menu, documentation and download packages.

This is an update to the same extension. Your Spaces, Favorites, pinned links, folders, preferences and backups carry forward. The GitHub repository remains at its existing address.

The complete 3.0 experience is included: automatic YouTube Picture-in-Picture, the sidebar mode switch, temporary new-tab reuse, custom link icons and all organization, search, migration and sync features.

### Install or update

Download `arc-side-of-the-chrome-v3.0.1.zip`, extract it and open **chrome://extensions → Developer mode → Load unpacked**. Select the folder containing `manifest.json`.

For an existing installation, replace the files in its current folder and click **Reload**. Reload already-open webpages, including YouTube, to apply the update. Your saved sidebar organization is retained.
