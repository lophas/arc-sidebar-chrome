## Arc Side of the Chrome 4.0.6

*Spaces, tabs & a little harmony.*

- Complete the Autohide-to-Fixed handoff from the sidebar button so the overlay cannot remain alongside the native panel. Stop stale overlay controllers before removing their host after an extension update.

For an unpacked installation, download `arc-side-of-the-chrome-v4.0.6.zip`, replace the files in your existing folder and click **Reload** at `chrome://extensions`.
For a Chrome Web Store upload, use `arc-side-of-the-chrome-v4.0.6-webstore.zip`.
