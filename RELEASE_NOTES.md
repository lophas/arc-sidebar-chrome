## Arc Sidebar for Chrome 1.2.3

### Fix

- **Folder drag-and-drop:** root folders can now be moved before or after pinned links, as well as other folders, within the same Space. An insertion indicator shows the destination, and the folder’s contents stay intact.

### Documentation

- The README consistently refers to **Arc Browser** and includes a prominent disclaimer that Arc Sidebar for Chrome is an independent extension developed entirely from scratch, without affiliation, endorsement or sponsorship by The Browser Company or Arc Browser.

All features from 1.2.2 are included, including focus-based Chrome group visibility, manual group control, Space open tabs, drag-to-pin and the search popup.

### Install or update

Download `arc-sidebar-chrome-v1.2.3.zip` and extract it. Open **chrome://extensions → Developer mode → Load unpacked**, then select the folder containing `manifest.json`.

For an existing installation, replace the files in its current folder and click **Reload**. Your saved sidebar organization is retained.
