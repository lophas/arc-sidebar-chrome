## Arc Sidebar for Chrome 1.2.2

Automatic Chrome group visibility now follows focus changes while leaving you free to arrange the tab bar manually between them.

### Improvements

- **Focus-based group visibility:** switching tabs or focusing a Chrome window expands the active tab’s Space or Favorites group and collapses the other managed groups in that window.
- **Manual group control:** expand or collapse groups yourself; your layout stays in place until the next focus change in that window.
- **Independent windows:** focus changes update only the affected window’s groups.
- **README screenshots:** a sidebar overview, inline search and the standalone search popup illustrate the documentation with an example workspace.

All features from 1.2.1 are included: Spaces, Favorites, folders, Space open tabs, drag-to-pin, complete Space closing, matching Chrome group order, Command+K / Ctrl+K search, Arc import, Chrome Sync and backups.

### Install or update

Download `arc-sidebar-chrome-v1.2.2.zip` and extract it. Open **chrome://extensions → Developer mode → Load unpacked**, then select the folder containing `manifest.json`.

For an existing installation, replace the files in its current folder and click **Reload**. Your saved sidebar organization is retained.
