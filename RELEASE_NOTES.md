## Arc Sidebar for Chrome 2.0.0

Organize saved links and live Chrome tabs together, with a consistent sidebar across your browsing workflow.

### Highlights

- **Favorites everywhere:** a shared destination picker puts Favorites first. Add an open tab directly to Favorites, move saved links between Favorites and Spaces, and reorder Favorites with drag-and-drop.
- **Drag across your sidebar:** move Favorites into Space roots or folders, move pinned links into Favorites, and scroll automatically when dragging near the list edges.
- **Coherent open tabs:** view live tabs by Chrome group, close a whole group, or close all open tabs with confirmation. Chrome-pinned tabs appear first with a distinct, read-only presentation.
- **Clear close controls:** centered live indicators turn into an × on hover and show a Close label across links, folders, tabs and groups.
- **Flexible autohide:** choose a 500–1100 ms delay or disable autohide for a fixed sidebar. The edge follows Chrome's Side panel position setting, and changes apply as you focus each tab.
- **Complete backups:** save and restore folder expanded/collapsed states, autohide timeout, Favorite button size and sidebar width alongside Spaces, Favorites, links, folders and icons.
- **Ready from the start:** fresh installations and resets create an empty Favorites collection and a selected 🚀 My Space. Helpful setup text and button tooltips guide the first steps; the last Space cannot be deleted manually.
- **Reliable browsing:** improved sidebar visibility when switching tabs, Favorites group behavior, and routing of new tabs opened from Favorites into the selected Space.

Arc Browser import, Chrome Sync, the search popup, persistent saved-tab bindings and all existing organization features remain available.

### Install or update

Download `arc-sidebar-chrome-v2.0.0.zip` and extract it. Open **chrome://extensions → Developer mode → Load unpacked**, then select the folder containing `manifest.json`.

For an existing installation, replace the files in its current folder and click **Reload**. Your saved sidebar organization is retained. Download a backup before updating if you want an additional copy.
