Automatic video mini player

Keep watching a playing HTML5 video when you switch tabs. It returns to the page when you switch back. Enabled by default; manually opened Picture-in-Picture stays open.

If the mini player doesn’t open, a setup popup appears when you return to the playing video. Choose Copy site & open PiP settings, then use Allowed → Add in Chrome to paste and save the website address. You can dismiss the popup for that website. Videos need to be playing with sound.

Manage Automatic picture-in-picture permissions in Chrome

Automatic tab discard

Keep idle tabs open while unloading their page contents from memory. They reload when you return, keeping their place in the sidebar and Chrome groups.

The timer starts when a tab becomes inactive. Active tabs in every window, Chrome pinned tabs, protected tabs, playing media, Picture-in-Picture, camera/microphone/screen sharing and detected unsaved edits are skipped.

Right-click a webpage and select Keep this tab in memory to protect that tab until you close it. These settings stay on this computer and are included in backups, not Chrome Sync.

Returning to a discarded tab reloads it. Add important editors and call sites to the exceptions: not every application exposes unsaved state. Pages opened before this extension update stay protected until reloaded so existing capture activity cannot be interrupted.

Autohide & edge trigger

Switch between Fixed and Autohide using the icon to the left of the sidebar search bar. Autohide is the default. Click outside the sidebar to hide it immediately; dragging does not reopen it.

Trigger area 100% height
Move either endpoint from 0–100%. The active area is at least 20% of the viewport height.
Edge trigger preview

The sidebar left/right position follows the Chrome Settings → Appearance → Side panel position setting. Changes apply immediately to the active tab, and to other open tabs when you next focus them.

⚠ Browser pages need a manual click Autohide does not work on Chrome’s own settings pages, the Chrome Web Store or browser error pages. A yellow ! on the toolbar icon marks pages where autohide is unavailable. Click the icon to open the fixed side panel.

Chrome Sync

Sync Spaces, Favorites, folders and pinned links between Chrome installations signed into the same Chrome Sync account.

On a fresh installation or after reset, Sync restores the existing cloud snapshot. The empty starting layout is never uploaded.

Live tab bindings, open tabs, collapsed folders, sidebar mode, overlay width, autohide timeout, edge trigger geometry, Favorite size and automatic discard settings stay local to each computer.

Arc import

Select Arc Browser’s StorableSidebar.json.

Where to find the file
macOS~/Library/Application Support/Arc/StorableSidebar.json

In Finder or the file picker, press ⌘ Shift G, paste the folder path, then select StorableSidebar.json.

Windows%LOCALAPPDATA%\Packages\TheBrowserCompany.Arc_*\LocalCache\Local\Arc\StorableSidebar.json

Paste the starting folder into File Explorer’s address bar. Open the folder beginning with TheBrowserCompany.Arc_, then LocalCache → Local → Arc and select StorableSidebar.json.

⚠ Import replaces ALL sidebar contentsAll existing Spaces, Favorites, folders, pinned links and icons are replaced, including My Space. Nothing from your current sidebar is kept. Download a backup first if you want to preserve it.
