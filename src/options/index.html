Spaces, tabs & a little harmony.

Automatic YouTube mini player

Keep watching a playing YouTube video when you switch tabs. It returns to the page when you switch back. Enabled by default; manually opened Picture-in-Picture stays open.

If Chrome asks, allow Automatic picture-in-picture for YouTube in the site controls next to the address bar. The video needs to be playing with sound.

Autohide timeout

Choose how long the sidebar stays open after the pointer leaves. Switch between Fixed and Autohide using the icon to the left of the sidebar search bar. Autohide is the default.

The sidebar left/right position follows the Chrome Settings → Appearance → Side panel position setting. Changes apply to each open tab when you next focus it.

⚠ Browser pages need a manual click Autohide does not work on Chrome’s own settings pages or browser error pages. Click the Arc Side of the Chrome extension icon in the toolbar to open the fixed side panel on these pages.

Favorite button size

Choose one of five fixed Favorite tile sizes. 100% is the original/default size.

Arc import

Select Arc Browser’s StorableSidebar.json.

Where to find the file
macOS~/Library/Application Support/Arc/StorableSidebar.json

In Finder or the file picker, press ⌘ Shift G, paste the folder path, then select StorableSidebar.json.

Windows%LOCALAPPDATA%\Packages\TheBrowserCompany.Arc_*\LocalCache\Local\Arc\StorableSidebar.json

Paste the starting folder into File Explorer’s address bar. Open the folder beginning with TheBrowserCompany.Arc_, then LocalCache → Local → Arc and select StorableSidebar.json.

⚠ Import replaces ALL sidebar contentsAll existing Spaces, Favorites, folders, pinned links and icons are replaced, including My Space. Nothing from your current sidebar is kept. Download a backup first if you want to preserve it.

Backup & restore

Download a portable JSON backup of your Spaces, Favorites, folders, pinned links, autohide timeout, Favorite button size and sidebar width, or restore one on this or another computer.

Chrome Sync

Sync Spaces, Favorites, folders and pinned links between Chrome installations signed into the same Chrome Sync account.

Live tab bindings, open tabs, collapsed folders, overlay width, autohide timeout and Favorite size stay local to each computer.
